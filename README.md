# Plataforma de Estudos ENEM 2027 — Foco Medicina USP

Acesse a plataforma gratuita pelo link:
👉 **https://adinonanda.github.io/enem-2027-project-free/**

## Avisos importantes antes de começar
- **Progresso privado:** Tudo o que você marcar fica salvo exclusivamente no seu próprio navegador. Ninguém mais tem acesso aos seus dados ou desempenho.
- **Use sempre o mesmo navegador:** Como o salvamento é local (`localStorage`), abra o site sempre no mesmo aparelho e navegador (evite aba anônima ou limpar os dados de navegação).
- **Faça backup regularmente:** Clique no botão **Exportar** dentro da plataforma para baixar seu arquivo de backup (`.json`). Se trocar de celular/PC ou formatar o aparelho, basta clicar em **Importar** para restaurar todo o seu progresso.
